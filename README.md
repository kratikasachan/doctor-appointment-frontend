# Doctor Appointment Booking (Frontend)

A responsive doctor appointment booking website built with React and Tailwind CSS. Backend (Flask + SQL) is in progress.

## Features
- Browse doctors by speciality
- Doctor details page
- Appointment booking page
- Login / Signup page
- Responsive design for mobile and desktop

## Tech Stack
- React
- Tailwind CSS
- JavaScript

## How to Run
1. Clone the repo
   git clone https://github.com/kratikasachan/doctor-appointment-frontend.git
2. Go to the frontend folder
   cd frontend
3. Install packages
   npm install
4. Start the app
   npm run dev
